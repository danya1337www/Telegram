# Telegram на UIKit

Проект — клон Telegram на UIKit. UI собран кодом, экран переписки построен на MessageKit. 

Реализовано:
- список чатов с поиском, свайп-действиями и контекстным меню с превью чата
- экран переписки на MessageKit: бабблы со временем внутри, кастомный инпут-бар с переключением кнопки отправки и микрофона
- счётчики непрочитанного, мьют и сохранение позиции скролла для каждого чата

Полностью готова только вкладка Chats — Contacts, Calls и Settings пока заглушки, часть свайп-действий тоже. Чаты лежат в локальном `mock_chats.json`, отправка сообщений работает в пределах сессии; аватары грузятся по сети.
